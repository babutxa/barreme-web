# Barrême

Score calculator for springboard and platform diving judges. Pick the degree of difficulty (DC) and the sum of the counted judges' scores, and Barrême shows the dive's points, following World Aquatics rule D 7.8.

**Open it at https://babutxa.github.io/barreme-web/**

## How to use it

1. **Choose the mode** at the top of the Score panel: *Individual* or *Synchro*.
2. **Tap the DC.** Each column is the whole number (1–4) and each row the decimal, so 2.8 is in column 2, row .8.
3. **Tap the sum of the counted scores.** Tap the same number again to add a half point (e.g. 21 → 21.5).
   - Individual: the 3 counted scores, from 0 to 30.
   - Synchro: the 5 counted scores, from 0 to 50.
4. **Read the result.** The calculation is shown below it, so you can check it against the sheet.

### Examples

- Individual: DC 2.8, scores 7 + 7.5 + 7 = 21.5 → 21.5 × 2.8 = **60.2**
- Synchro: DC 2.8, counted scores sum 35.5 → 35.5 : 5 × 3 = 21.3 → 21.3 × 2.8 = **59.64**

## Install it on your phone or tablet

Barrême works in any browser and can be installed like an app. Once it has been opened, it also works without an internet connection.

- **iPhone / iPad (Safari):** tap Share → *Add to Home Screen*.
- **Android (Chrome):** tap the ⋮ menu → *Install app* (or *Add to Home screen*).
- **Computer (Chrome / Edge):** click the install icon in the address bar.

## Privacy

Barrême stores nothing about you. It counts anonymously how many calculations are made (with [GoatCounter](https://www.goatcounter.com/)), without cookies or personal data.
